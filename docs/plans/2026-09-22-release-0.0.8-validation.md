## Findings corrected before publication

- A modal unmounted while its opening backdrop was animating could be reattached to `body` by
  Bootstrap. A real-browser reproduction found one orphan element; owned disposal now removes it.
  Twelve transition tests cover opening, open and closing in all four theme/viewport projects.
- A paginated stack group displayed the visible slice's size as its container count. The header now
  preserves the complete group count, with a test for a group spanning pages.
- Visual fixture imports now match the application's Bootstrap modules, and its dependency cache is
  separate from E2E. The displayed fixture version is fixed so release bumps do not alter screenshots.
- Eight reference images for the overview and About/update screen were reviewed and intentionally
  updated for the previously requested container links and separate update controls. Other baselines
  were retained; the final complete visual run passed without snapshot updates.
- Performance-only helpers and their synthetic Docker CLI are excluded from the production image.

The E2E files fixture intentionally changes its Compose/environment selection. Its old teardown
command could not parse the resulting default Compose invocation. The remaining test container and
empty project network were identified by their fixture working-directory/project labels and removed
explicitly after the runs. Existing user containers were not modified.

The preexisting extra blank line in `CreateStackSheet.vue` remains a lint warning, not an error.
Performance measurements and their scope are in [the implementation report](2026-09-22-performance-results.md).
The local 30 minute constrained screen does not certify a dedicated VPS, 24 hour soak or three remote
agents; no new universal hardware minimum is claimed by this release.
