# Dockge2 0.0.12

This release completes the transition to verified self-updates for panels whose old installation
script pulled the published `0.0.10` image without installing the new host updater. Version
`0.0.10` could run successfully in that state but could not import itself into its signed updater.

The signed `0.0.12` contract recognizes that exact unmanaged image by registry digest, source
revision, schema and vendor Compose hash. Unknown or locally rebuilt images are refused before
cutover. The updater retains the running image, verifies a stopped-data snapshot, checks the new
panel's readiness and preserves rollback. Existing managed `0.0.10` installations update through
their installed launcher.

Download the `install.sh` attached to this release for an unmanaged installation, and run it with
`--update --dir /opt/dockge2 --version 0.0.12 --dry-run` before `--yes`. A managed installation
uses `/opt/dockge2/.dockge2/update --update --dir /opt/dockge2 --version 0.0.12` with the same
preview and acceptance sequence. Use the actual installation directory on each host.

The release gate tests both migrations and rollback on `linux/amd64` and `linux/arm64`. See
[installation, trust and recovery](https://github.com/mazixs/dockge2/blob/v0.0.12/docs/self-updates.md).
