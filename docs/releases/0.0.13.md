# Dockge2 0.0.13

This release puts the server console under the owner's control and gives every user shells of
their own, moves MCP to protocol `2026-07-28`, repairs image update checks for multi-platform images
and tells a stopped stack from a crashed one. Update if several people share one panel: until now a
second user could join another user's live shell.

## Updating

A managed installation updates with its installed updater; use the actual installation directory:

```bash
sudo /opt/dockge2/.dockge2/update --version 0.0.13 --dry-run
sudo /opt/dockge2/.dockge2/update --version 0.0.13 --yes
```

`DOCKGE_ENABLE_CONSOLE` is no longer read. An installation that turned the console on with it
comes up with the console off until an owner turns it on in Settings -> Security. The variable may
stay in `.env`; it has no effect. The update adds columns to the MCP access log table and changes no
stack files. See [updating](https://github.com/mazixs/dockge2/blob/v0.0.13/docs/updating.md).

## Console and shells

- The owner turns the console on in Settings -> Security, confirming with the password, and turning
  it off ends the open sessions. Only owners open it until an owner lets operators in, again with
  the password.
- Every user gets a console session and container shells of their own. A shell used to be shared by
  name, and `terminalJoin` returned the scrollback of any terminal; joining, input, leaving and
  resizing now reach only the caller's own session or shared output. A panel names its users to an
  agent, so the separation holds on agents too.
- Changing, suspending, resetting or deleting an account ends the shells it left open, and every
  such change asks the acting owner for their password.

See [accounts and roles](https://github.com/mazixs/dockge2/blob/v0.0.13/docs/authentication.md).

## Stacks

- A stack whose containers all exited reads as stopped when the exit code is zero. Any other code,
  or one that cannot be read, is an error and shows the code: "error, code 1". A failed stack sorts
  first and counts under "Needs attention"; a stopped one no longer shows a failure reason.
- Compose projects started outside Dockge are folded under "Other projects" at the bottom of the
  list. A search, a filter or an open foreign stack unfolds them.
- Image update checks ask the registry API directly instead of `docker manifest inspect`, which
  failed for every multi-platform image with "the registry did not answer". Credentials from
  `docker login` go only to an HTTPS realm, and an unknown result names its cause: refused access,
  missing tag or no answer.
- Pressing Edit on an env file reveals its values at once.
- The external network picker lists the stack's own networks first and folds the rest.
- Leaving the editor asks only when something was edited, the stop and delete dialogs name the stack
  and "0 s ago" reads "just now".

## MCP

- The endpoint serves protocol `2026-07-28` through the official SDK v2; `2025-11-25` clients keep
  working. It accepts POST only.
- The settings page shows the state, endpoint, encryption, active keys, last connection and last
  refusal. Plain HTTP beyond loopback needs an explicit opt-in.
- "Connect a client" gives configurations for Claude Code, Cursor, VS Code, Codex CLI and Gemini CLI,
  plus a curl check. Each reads the key from `DOCKGE_MCP_KEY`.
- The access log records connections, tool listings, refusals with their reason and address, and
  owner actions. Repeats are counted per minute, so a flood of refusals cannot push history out.

See [MCP](https://github.com/mazixs/dockge2/blob/v0.0.13/docs/mcp.md).

## Interface

- The sign-in screen offers the language next to the theme. English is the default at setup and
  after a reset; the browser language is no longer used.
- A locked compose or env editor rejected typing but accepted paste, drop and cut. It is read-only
  while locked now, and pasting a compose file there no longer opens "New stack".
- Toasts no longer put a horizontal scrollbar on the page, and their close button works.
- The stack list no longer scrolls sideways, dimmed rows keep a readable contrast and inner panels
  get a thin scrollbar.

## Documentation

The README describes the product, the changes from Dockge, installation, updating and the license.
Detailed guides moved into `docs/`: installation, updating, configuration, stacks from Git, FAQ and
development. Two-factor authentication and owner password recovery are documented, the MCP guide is
rewritten, and the screenshots show the English interface with invented data.

## Development

CI runs lint, type checks, the bundle budget and the updater contracts once on the pinned Node and
tests on both supported versions, on runners pinned to `ubuntu-24.04`. The unused nightly workflow
is removed. The agent protocol contract is a closed set, so a call to an event that does not exist
no longer compiles. The terminal browser tests wait for the shell prompt instead of fixed pauses.
