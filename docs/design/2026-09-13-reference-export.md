# Замороженный экспорт макета: где он и почему его больше нет в дереве

Дата: 2026-09-13. Удален из рабочего дерева 2026-09-16.

`docs/design/reference/` содержал полный экспорт выбранного макета: 42 файла и около 2,4 МБ -
скомпилированные чанки Next.js, CSS публикации, шрифты IBM Plex, восемь снимков сравнения и
`design-system.html` со шрифтами в base64. Приложение ничего оттуда не импортировало: это был
эталон для глаз на время реализации направления "01 Знакомый Dockge".

Реализация закончена (A0-A5 из [аудита Sites](2026-09-11-sites-audit-and-plan.md)), а роль эталона
перешла к `test/visual/baseline/`: 28 снимков настоящих компонентов, которые проверяет
`npm run test:visual` и которые падают при расхождении. Замороженная копия чужой сборки этого не
проверяла и просто лежала в публичном репозитории.

## Как достать обратно

```sh
git show 39f78b2:docs/design/reference/README.md     # что там было и как это запускалось
git checkout 39f78b2 -- docs/design/reference        # вернуть каталог целиком
```
