# Реализация выбранного Dockge2

Пользователь выбрал "Знакомый Dockge" и разрешил реализацию. Дополнительно подтвердил несколько учетных записей, создаваемых владельцем, без открытой регистрации.

## Контракт

- Постоянный компактный список стеков слева; рабочая область справа. Главная показывает стабильность, а создание открывается по действию пользователя.
- Прямые переходы к обзору, Compose/окружению и журналу. Существующие создание из docker run, сохранение без запуска, обновление образов, агенты, секреты и терминалы сохраняются.
- Тема по умолчанию системная. Явный выбор светлой/темной/системной сохраняется на устройстве и доступен до входа. Системная тема реагирует на изменения ОС без перезагрузки.
- better-auth остается основой сессий и паролей. Первый владелец создается с подтверждением владения экземпляром. После настройки публичная регистрация закрыта на сервере.
- Владелец создает операторов и наблюдателей, меняет их пароль и отзывает доступ. Права проверяются сервером, включая операции через агент и терминал. Наблюдателям не выдаются файлы с секретами и интерактивная оболочка.
- Uptime контейнера означает время с запуска Docker, доступность за период означает долю наблюдаемого времени. Неизвестные периоды не становятся успешными наблюдениями. Периоды: 24 часа, 7 дней, 30 дней.
- Новый Git clone/fetch/diff не входит в эту реализацию: интерфейс показывает только сведения, доступные из существующего серверного кода.

## Задачи и границы изменений

- [x] Интерфейс и темы: Layout.vue, Dashboard.vue, StackList/StackListItem, StackInspector.vue, тема, токены. Общий обзор размещается через отдельный компонент StabilityDashboard. Управление агентами остается доступно в настройках.
- [x] Авторизация: backend/auth*, проверка прав Socket.IO/agent, защищенная первоначальная настройка, Login/Setup и отдельный компонент Users.vue. Изменения auth в dockge-server/socket mixin выполняются отдельно от визуальной части.
- [x] Стабильность: самостоятельный обработчик stabilityOverview, общие типы и расчет, запись наблюдений, Docker uptime, StabilityDashboard.vue. Контракт ответа определяется этой задачей и сообщается при интеграции. Обработчик регистрируется в общем списке без изменения авторизации.
- [x] Интеграция: маршруты и настройки, доступность кнопок по роли, локализация ru/en, общие визуальные состояния.
- [x] Проверка: модульные проверки изменения прав/регистрации/uptime/наблюдений/темы, lint, TypeScript, покрытие, сборка, браузер desktop/mobile и три режима темы, независимый просмотр итоговых изменений.

## Организация

Используется текущая рабочая копия на отдельной ветке mzx/familiar-dockge. Незакоммиченные AGENTS.md и прежние документы дизайна сохранены. В соответствии с навыком dispatching-parallel-agents независимые задачи авторизации и стабильности выполняются отдельно, интерфейс и интеграция - в основной задаче. Общее изменение схемы ответа и пересекающихся файлов согласуется до редактирования. Тестовые базы и стеки изолируются, пользовательские контейнеры не изменяются.

## Проверки перед началом

| Части | Общая граница | Решение |
| --- | --- | --- |
| Авторизация / стабильность | Вызов обработчика и проверка роли | Отдельный stability handler; разрешение чтения задается проверкой прав |
| Авторизация / интерфейс | Пользователь, роль, настройки | Авторизация добавляет canManageStacks и isAdmin; интерфейс использует их |
| Стабильность / интерфейс | Страница общего обзора | Отдельный StabilityDashboard.vue подключается на главную |
| Все части | Локализация | Новые ключи независимыми группами, изменения объединяются без перезаписи |
