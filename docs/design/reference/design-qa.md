# Визуальная проверка локального эталона

Дата: 2026-09-13. Область: экспорт Sites 01 и каталог предложения. Приложение не изменено, дизайн-план ожидает утверждения.

## Результат

**Passed для настольного экспорта и просмотренного каталога.** Это не приемка дизайна приложения и не проверка всех сценариев исходного прототипа.

- Версия Sites 1 и локальный коммит совпадают. Проверены SHA-256 всех 20 исходных ресурсов из `provenance.json`; HTML отличается документированными вставками локальной навигации и оболочки.
- Визуально просмотрена объединенная пара `evidence/export-comparison.png`: опубликованный обзор с обрезанной презентационной рамкой слева, локальный обзор справа. Совпадают композиция, шрифты, цвета, значки, таблица и источник. Рамка и внешние отступы намеренно исключены.
- Настольные обзор и создание сняты при 1390 x 1000. Пары Git имеют одинаковый выходной размер 1375 x 989. Каталог содержит шесть принятых снимков; все изображения загрузились.
- Проверены переходы между тремя демонстрационными сценами, форма создания и переход к проверке, выбор результата Git и экран проверки. Это только демонстрация без Docker/Git.
- Каталог просмотрен в светлой теме; проверены переключатели светлой, темной и системной темы и ответ демонстрационной кнопки. При ширине 390 px просмотрена типографическая секция; горизонтального переполнения страницы нет.
- Найденные неверные относительные ссылки из каталога в сцены исправлены и повторно проверены по адресам браузера.
- Первые снимки фоновых вкладок с повторяющимися фрагментами отвергнуты. В `evidence/` включены только повторно снятые, визуально просмотренные кадры.

## Сравнение с приложением

`evidence/create-comparison.png` показывает эталон и настоящие Vue-компоненты на изолированной тестовой сцене. Остальные пары находятся в `system.html`. Зафиксированы отличия плотности, геометрии формы, кнопок, подписей, источника и Git-сравнения. Конкретные измерения и план исправлений находятся в `design-plan.md`.

Состояния второстепенных стеков, число строк diff и исходные данные различаются. Это не строгий пиксельный тест на одинаковых данных. Перед приемкой внедрения данные необходимо выровнять.

## Ограничения и следующие проверки

- Полное парное мобильное сравнение Sites и экспорта не принято: первоначальный мобильный снимок был технически искажен. Мобильная приемка приложения, 200% текста и полная клавиатурная матрица остаются в S3-S6.
- Каталог 0.1 является предложением, а не готовой библиотекой Vue. Все сочетания контраста и состояния компонентов необходимо проверить при внедрении.
- Не проверялись вход, производительность, безопасность и реальные операции контейнеров. Данные пользователя не менялись.
- Проверены синтаксис экспортера, исходные контрольные суммы и пробельные ошибки в измененной документации. Проверки приложения не запускались: изменения этой задачи ограничены документацией и локальным эталоном.
