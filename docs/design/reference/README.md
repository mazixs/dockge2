# Локальный эталон Dockge2 и предложение дизайн-системы

Статус: дизайн-план ожидает утверждения. Рабочее приложение не изменяется.

Запуск из корня репозитория:

```sh
python3 -m http.server 5095 --bind 127.0.0.1 --directory docs/design/reference
```

- `http://localhost:5095/` - исходный выбранный макет Sites 01, без оболочки.
- `http://localhost:5095/?screen=create` - создание.
- `http://localhost:5095/?screen=changes` - Git-сравнение.
- `http://localhost:5095/system.html` - предложение дизайн-системы, сравнение и план.

Превью использует локальные HTML/CSS/JS/WOFF2. Открывайте через HTTP, не через file://. Демонстрационные операции не подключаются к Docker или Git. Часть обещаний исходного макета упрощена; они не являются контрактом рабочего приложения.

`provenance.json` фиксирует исходную версию и контрольные суммы. `source.css` - исходный читаемый CSS Sites; `_next/` и `fonts/` - замороженные ресурсы опубликованного макета, намеренно сохраненные как эталон. `standalone.css` меняет только презентационную оболочку. `proposal.css` применяется только к каталогу предложений. Ни один из этих файлов не импортируется приложением.

Повторный экспорт: `python3 docs/design/reference/export.py /путь/к/dockge2-directions`. Скрипт проверяет коммит опубликованной версии; после экспорта надо повторить визуальную проверку. Он не публикует сайт и не запрашивает учетные данные.

Снимки в `evidence/` показывают только вымышленные данные. Непринятые технически искаженные снимки не включаются. Полный ход проверки и ограничения: `design-qa.md`. Лицензии IBM Plex находятся в `fonts/OFL-*.txt`.
